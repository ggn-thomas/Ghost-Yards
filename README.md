# Ghost Yards - Thomas Gaugain & Noah Palissier

Sur les semaines 1 à 8 de 2021, **Amari Cooper est le receveur le plus souvent laissé de côté alors qu'il était la meilleure option : 25,1 yards attendus par match** offerts sans recevoir le ballon (Evan Engram chez les TE avec 14,1, Austin Ekeler chez les RB avec 5,1).
À l'instant du lancer, un modèle estime les yards attendus de chaque receveur à partir du tracking Next Gen Stats. Les ghost yards mesurent ce que le meilleur receveur ignoré, plus ouvert que la cible, offrait de plus qu'elle.
Dans 41 % des passes, un receveur plus libre offrait davantage.
**Démo :** VERCEL_URL · **Algorithme, limites et commande pour relancer :** [algo.md](algo.md) · `python -m src.run_all` regénère `web/public/data.json`.
